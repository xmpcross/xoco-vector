## Added

- Added a dedicated release-note presentation for posts in the Updates category.
- Added optional `release` frontmatter with version and release type.
- Added tech-focused sample content across engineering, AI, cloud, security, hardware, design systems, and guides.

## Changed

- Reworked the homepage to lead with a large featured post instead of the old blog notice.
- Updated the logo treatment to use the Vector wordmark without the upward icon.

## Upgrade Notes

Existing update posts continue to work without the new `release` object. Add it when you want the version chip and release-type badge in the details panel.
